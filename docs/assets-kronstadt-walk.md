# Картинки пешего квеста `kronstadt-walk`

Сопоставление кодов картинок с файлами в `assets-src/kronstadt-walk/images/`.

Источники:
- коды и описания станций 1–2 — `docs/tz-stancii-1-2.md`, раздел «Ассеты» → «Картинки»;
- полный список кодов, латинские ID и где какая картинка используется — решение Саши (27.10.2026),
  записано в этом файле.

Файлы — оригиналы, без сжатия и переименования.

## Правило по умолчанию

Пока звучит реплика, на экране тот, кто говорит:

| Ситуация | Картинка |
| --- | --- |
| Федот рассказывает | Ф1 |
| Федот после правильного ответа («Есть страница!») | Ф4 |
| Подсказки | К3 |
| Реплики Клуши | К1 |
| Страница журнала (фон под текстом) | Ж2 |

Ниже в столбце «Где используется» указано, где картинка отличается от этого правила.
