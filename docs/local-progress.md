# Сохранение прогресса на одном устройстве

Статус: реализовано в рабочей копии. Публикация и проверка владельцем на телефоне — отдельно.
Исходная версия GitHub: 2d85460f743d2d60d32e6c903e163f9ebc7a238a.

## Поведение

- Ключ браузера: `kronstadtkvest:progress:kronstadt-walk`. Общий для `/dev/start`, `/dev/station-1`, `/dev/station-2`.
- Сохраняются имена, история и текущий основной экран (включая подсказку, реплику после ответа и служебный конец), ответы и использованные подсказки, найденные страницы и первое пояснение карты.
- Запись происходит при действии игрока, а не при закрытии вкладки. Ответ и награда, подсказка и её экран записываются вместе.
- При загрузке сначала читается и проверяется запись. Открытие страницы само по себе ничего не записывает.
- Аудио не запускается само после восстановления. Позиция аудио, раскрытая панель чтения и полноэкранная картинка не сохраняются.
- Обе кнопки перезапуска требуют подтверждения. Отмена ничего не сбрасывает. Подтверждение удаляет только этот ключ и возвращает к началу части, указанной открытым служебным адресом.
- При переходе, перезапуске или закрытии экрана отменяется ожидающий переход к реплике героя.
- Формат имеет версию и описание структуры сценария. Изменение текста не сбрасывает прогресс; несовместимая структура и повреждённые записи не применяются. Старая запись заменяется при следующем действии игрока.
- Запрет или переполнение localStorage не ломают квест, но сохранение тогда невозможно. Данные зависят от браузера и адреса сайта, не переносятся между устройствами; очистка данных сайта удаляет прогресс. Одновременное прохождение в нескольких вкладках не поддерживается.

## Проверки для разработчика

Node.js 22.18+:

```sh
node --test tests/questProgress.test.mjs
npm run lint
npm run build
```

Для отдельной проверки в браузере используется Playwright (не входит в зависимости сайта):

```sh
QUEST_TEST_URL=http://localhost:3000 NODE_PATH=/path/to/test-tools/node_modules node tests/progress-browser.mjs
```

`CHROMIUM_PATH` задаёт путь к Chromium. Проверка использует отдельный временный профиль, размер экрана 390×844 и настоящие сценарии обеих станций. Она также закрывает и повторно запускает браузер с тем же профилем.

## Проверка владельцем после публикации

Адрес: https://sasha-novaya-kronstadtkvest-634d.twc1.net/dev/start

1. Нажать «Мы на месте», вписать имена, обновить страницу — имена остались.
2. Дойти до задания, открыть подсказку, закрыть и открыть квест — вернулась подсказка с тем же номером.
3. Решить задание, перейти к журналу и повторно открыть квест — вернулась страница, решение осталось.
4. На второй станции вписать год, продолжить и повторно открыть квест — место остановки сохранилось.
5. Нажать «Начать заново» и отменить — ничего не потерялось. Повторить с подтверждением — прохождение сбросилось, после обновления оно не возвращается.
6. Проверить звук, чтение и увеличение картинок на своём телефоне.

## Возврат к прежней версии

В локальной истории есть отдельное исходное состояние перед изменениями. Изменения делаются вне `main`; в GitHub и Timeweb пока не отправлены. Перед публикацией нужна проверка актуальной `main` и прав доступа. Для отмены опубликованных изменений следует отдельным изменением вернуть затронутые исходные файлы и убрать новые модули. Остальные файлы, сценарии и оформление не затрагивать. Откат кода не удаляет записи в браузерах игроков.
