## Шрифты

- Шрифт Hirro Sans — Дмитрий Антонов / Blue Curve Designstudio, CC BY 4.0, https://creativecommons.org/licenses/by/4.0/

- Шрифт Nunito — The Nunito Project Authors, SIL Open Font License 1.1, https://openfontlicense.org
  (подключён через пакет `@fontsource/nunito`, файлы хранятся у нас).
